# 📦 Cadastro de Clientes em Java

Projeto simples desenvolvido em Java com o objetivo de praticar conceitos de orientação a objetos.

## 🚀 Funcionalidades

* Cadastro de cliente
* Associação de múltiplos endereços
* Associação de cartões de pagamento

## 🧠 Conceitos aplicados

* Classes e objetos
* Enum
* List (coleções)
* Relacionamento entre entidades (1:N)

## 📁 Estrutura

* `model` → classes do sistema
* `app` → execução do programa (Main)

## ▶️ Execução

Execute a classe `Main.java` para testar o funcionamento do sistema.
